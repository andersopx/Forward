# 转发脚本（已合并）

当前已将 `nat-zf-v4.2-aly.sh` 的云主机公网识别与交互优化能力合并进主脚本 `nat-zf-v4.2.sh`。

## 使用方式

- 主入口：`bash nat-zf-v4.2.sh`
- 兼容入口：`bash nat-zf-v4.2-aly.sh`（内部会自动转发到主脚本）

## 合并后的优化点

- 自动识别云平台公网 IP，并在规则展示中优先显示公网访问地址。
- 新增目标端口模式选择（固定 1701 / 同端口转发 / 自定义端口）。
- 支持直接修改已有规则（保留编号，运行中规则自动重启应用变更）。
- 删除规则后会自动重排编号（1..N 连续），并同步日志编号。
- 规则总览隐藏“出口网卡”列，减少重复信息，提升可读性。
- 降低双脚本维护成本：后续仅需维护 `nat-zf-v4.2.sh`。

- 新增端口限速管理：支持按端口/端口段（如 10001-10005）设置多条限速，并在规则总览显示命中的限速。
- 限速规则删除后同样会自动重排 ID，便于持续管理。
- 修复限速重排后的残留规则问题：删除限速后会先卸载旧规则，再按新ID重载。
- 限速端口段遵循 iptables multiport 限制（单条最多15段），超限会提示拆分。
- 新增限速若应用失败会自动回滚，避免数据库与内核规则不一致。
- 新增“全脚本检查并修复”入口，可一次执行规则/限速文件修复与运行态重载。
